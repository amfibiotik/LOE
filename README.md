# Power Schedule Optimizer

Інструмент для оптимізації робочого графіку на основі графіків відключень електроенергії у Львові.

## 🚀 Швидкий старт

```bash
# 1. Встановлення глобальних команд (один раз)
./install.sh

# 2. Активація (або відкрий новий термінал)
source ~/.zshrc

# 3. Використання
power-status    # Вся інформація відразу!
```

## 📋 Команди

### Глобальні (з будь-якого місця):
```bash
power-status      # ⭐ Вся інформація
power-plan        # План на день
power-check       # Графіки
power-changes     # Зміни
power-recommend   # Рекомендація
```

### Локальні (з папки проекту):
```bash
./status.sh       # Вся інформація
./plan.sh         # План на день
./check_today.sh  # Графіки
./changes.sh      # Зміни
./recommend.sh    # Рекомендація
```
