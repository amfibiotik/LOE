# Інструкція для використання

## ✅ Все вже налаштовано!

Ваші черги:
- 🏠 Основна квартира: **група 4.2**
- 🏘 Стара квартира: **група 6.2**

## Швидкий запуск

### Варіант 1: Через скрипти (найпростіше)

```bash
# Подивитись графік на сьогодні
./check_today.sh

# Отримати рекомендацію де працювати зараз
./recommend.sh
```

### Варіант 2: Через Python

```bash
# Активувати віртуальне середовище
source venv/bin/activate

# Графік на сьогодні
python -m src.cli today

# Рекомендація
python -m src.cli recommend
```

## Що показує програма?

### `./check_today.sh` - Графік відключень
Показує коли буде відключено світло на обох квартирах сьогодні.

Приклад виводу:
```
📅 Графік на 18.01.2026

Основна квартира (група 4.2):
  ❌ Відключення: 00:00-00:30, 10:30-11:00

Стара квартира (група 6.2):
  ❌ Відключення: 00:00-00:30, 10:30-14:00, 21:30-24:00
```

### `./recommend.sh` - Рекомендація
Аналізує графіки і каже де краще працювати прямо зараз.

Приклад виводу:
```
💡 Рекомендація (зараз 14:57):

📍 Основна квартира
💬 Вдома є світло
```

## Додаткові можливості

### Змінити робочі години

Відредагуйте `config.yaml`:
```yaml
work_hours:
  start: "09:00"  # початок робочого дня
  end: "18:00"    # кінець робочого дня
```

### Запустити тести

```bash
source venv/bin/activate
pytest tests/ -v
```

## Troubleshooting

**Помилка "command not found":**
```bash
chmod +x *.sh
```

**Помилка "No module named...":**
```bash
source venv/bin/activate
pip install -r requirements.txt
```

**Не показує дані:**
- Перевірте інтернет-з'єднання
- API Львівобленерго може бути тимчасово недоступним
