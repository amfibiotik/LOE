# Power Schedule - Швидка довідка

## 🚀 Готово до використання!

### ⭐ Головна команда:

```bash
./status.sh    # ВСЯ ІНФОРМАЦІЯ ВІДРАЗУ
```

### Інші команди:

```bash
./check_today.sh    # Графік відключень
./plan.sh           # План на день
./changes.sh        # Зміни в графіках
./recommend.sh      # Рекомендація зараз
```

### Ваші налаштування:
- Основна квартира: група 4.2
- Стара квартира: група 6.2

### Структура проекту:

```
power-schedule/
├── check_today.sh      # Скрипт для перевірки графіку
├── recommend.sh        # Скрипт для рекомендації
├── config.yaml         # Ваші налаштування (черги)
├── src/
│   ├── fetcher.py     # Отримання даних з API
│   ├── parser.py      # Парсинг графіків
│   ├── scheduler.py   # Логіка рекомендацій
│   ├── cli.py         # CLI інтерфейс
│   └── bot.py         # Telegram бот
└── tests/             # Тести (TDD)
```
